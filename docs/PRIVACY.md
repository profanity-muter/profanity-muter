# Privacy policy source

The published policy is https://profanity-muter.github.io/privacy/
(repo profanity-muter/profanity-muter.github.io, privacy/index.html).

The "Feedback pages" section, in short: uninstalling, or tapping the popup's
"Paused for a while?" link, opens the feedback page. Its address holds only
the version number and where you came from. Answering is optional. Reason taps
are counted anonymously with Umami (no cookies, no IP addresses stored).
Comments you choose to send go to profanity.muter@gmail.com via Formspree, are
used only to improve Profanity Muter, and are deleted after 12 months.
